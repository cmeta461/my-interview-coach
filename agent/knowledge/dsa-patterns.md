# Data Structures and Algorithms Patterns

## Two pointers and sliding window
Use for sorted arrays, pairs summing to a target, and longest or shortest substring problems. Time is usually linear. Example question: longest substring without repeating characters.

## Hash maps
Trade space for time. Use for counting, grouping anagrams, and the two sum problem in linear time.

## Binary search
Works on sorted data or any monotonic condition, including searching on the answer. Time is logarithmic. Watch for off by one errors and overflow.

## Trees and graphs
Use depth first search for paths and backtracking, and breadth first search for shortest paths in unweighted graphs and level order traversal. Track visited nodes to avoid cycles.

## Dynamic programming
Identify overlapping subproblems and optimal substructure. Define the state, the transition, and the base case. Start with recursion and memoization, then optimize to a table. Example questions: climbing stairs, coin change, longest common subsequence.

## What interviewers grade
Clarifying questions, a brute force baseline, an optimized approach, correct complexity analysis, edge cases such as empty input and duplicates, and clear communication.
