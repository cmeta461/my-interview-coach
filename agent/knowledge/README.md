# Knowledge base

Drop any markdown (`.md`) files in this folder and the interview coach will use them.

- Files are split on headings, so use `#` / `##` headings for topics.
- The first `# Heading` becomes the document title.
- Add, edit or delete files at any time. The coach picks up changes on its next lookup, with no restart.
- Use a different folder by setting `KNOWLEDGE_DIR` in `.env.local`.
- This README is ignored by the coach.

Good things to add: company interview guides, question banks with model answers, system design notes, your own weak-spot cheat sheets, rubrics.
